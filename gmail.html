Reminder System

The Gmail Apps Script daily trigger checks the billing dates and sends reminders according to the settings.
  1. Before billing date: reminder according to configured days.
  2. On billing date: optional reminder.
  3. After billing date: overdue reminders.
  4. Email history is used to avoid duplicate reminders.
After changing the Apps Script code or Gmail permissions, redeploy the Web App and authorize the Gmail permissions from the Apps Script editor.
